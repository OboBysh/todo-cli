# Todo CLI Utility

CLI-утилита для управления списком дел.  
Разработана в рамках учебного кейса по модульной разработке и Git.

## Установка и запуск

1. Клонируйте репозиторий.
2. Создайте виртуальное окружение: `python -m venv venv`
3. Активируйте: `source venv/bin/activate` (или `venv\Scripts\activate` на Windows)
4. Запустите: `python main.py`

## Команды

- `add <текст>` – добавить задачу
- `list` – показать все задачи
- `complete <id>` – отметить выполненной
- `delete <id>` – удалить задачу
- `exit` – сохранить и выйти

## Модули

- `task_logic` – бизнес-логика
- `file_manager` – работа с JSON
- `error_handler` – обработка ошибок
- `cli_interface` – интерфейс командной строки
